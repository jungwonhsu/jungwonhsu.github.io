# Shokz OpenDots Air E210 - MVT Demo Page

Đây là trang web thương mại điện tử mẫu (mô phỏng giao diện Coupang) được thiết kế tối ưu hóa để thực hiện thử nghiệm đa biến (Multivariate Testing - MVT) trên nền tảng **VWO (Visual Website Optimizer)**.

## 📂 Cấu trúc dự án
Kho lưu trữ bao gồm 3 tệp tĩnh chính:
- `index.html`: Khung sườn và bố cục chính của trang sản phẩm (đã ghim sẵn các ID/Selector chuẩn cho VWO).
- `style.css`: Tệp định dạng giao diện, màu sắc và bố cục (Grid/Flexbox).
- `script.js`: Xử lý tương tác người dùng (chuyển đổi sản phẩm gợi ý, cuộn mượt đến phần bình luận, chọn màu sắc).

## 🚀 Hướng dẫn triển khai
1. Tải toàn bộ mã nguồn lên kho lưu trữ GitHub của bạn.
2. Vào **Settings** -> **Pages** của repository để bật tính năng **GitHub Pages**.
3. Lấy đường link trang web sau khi deploy và dán vào VWO để bắt đầu thiết lập chiến dịch MVT.
